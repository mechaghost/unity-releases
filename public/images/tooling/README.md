# Tooling card artwork

`unity-cli-official.png` is the unmodified 512 × 178 graphic from Unity's official CLI announcement:
https://discussions.unity.com/t/announcing-the-unity-cli-a-new-way-to-connect-your-tools-and-agents/1731104/1

Original image:
https://europe1.discourse-cdn.com/unity/original/4X/b/c/3/bc3c12beac230b5c2721c801c1386516f12ff1d4.png

Retrieved October 25, 2026. Artwork belongs to Unity. Its embedded beta.1 version is historical launch artwork, not the current release version; the card caption makes this clear.

The Pipeline treatment is HTML text styled to match the dark background and blue terminal lettering. It is not an official Pipeline logo.
